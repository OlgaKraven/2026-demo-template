Его утверждение об отсутствии конкретных материалов 2027 устарело для переданного набора: титулы трёх КИМ содержат утверждение приказом ИРПО от 27.08.2026 № 01-09-285/2026.

Критерии извлечены из таблицы 7 каждого документа. Страницы: 2026 — веб 13, ИС 12, программист 12; 2027 — все три на странице 13. Таблицы времени: 2026 — 29, 27, 28 соответственно; 2027 — 29, 28, 30. Суммы критериев проверены программно. Ссылки на PDF с номерами страниц встроены в сайты.

Критерий не равен модулю. Баллы не разнесены произвольно по отдельным кнопкам, формам или SQL-операциям. Показана официальная формулировка оцениваемого результата и её максимум. Автоматическое оценивание отсутствует.

Реестр `reports/sources/inventory.json` содержит пути, размеры, реальные SHA-256, число страниц PDF и оглавления ZIP. PDF извлечены в текст; карты шести редакций предметно сверены. Архивы приложений проинвентаризированы, но содержащиеся внутри Excel, Word и изображения не прошли полную содержательную сверку. Они не подставлены в авторские тренировочные варианты.

## Изменения шаблона

- Полное наименование специальности видно в шапке.
- Отдельные карты 2026 и 2027 с максимумом, длительностью, критериями, документом и страницей.
- Тема переключается кнопкой луны/солнца; выбор сохраняется локально.
- Таймер каждого модуля/задания: старт, пауза, продолжение, завершение, сброс и перерасход. Норматив 2027 отдельный, сохранение изолировано по редакции.
- Учебная связка «каталог V00»: HTML/JavaScript или Web Components; Python или Node.js; SQLite или JSON. Восемь комбинаций с единым API-контрактом и скачиванием исходников.
- Сохранены прежние SQL-маршруты PostgreSQL/MySQL/SQL Server, алгоритмы Python/C#/Java и веб-пример.

Пример каталога — небольшая работающая связка слоёв с чтением данных. JSON не заменяет СУБД экзамена, а каталог не заменяет обязательные авторизацию, редактирование и остальные функции задания. Соединение Python/Node с PostgreSQL/MySQL/SQL Server в этот комплект не входит; прежние SQL-маршруты самостоятельны.

## Повторное использование

Общая оболочка: `src/`. Данные: `content/<program>.json`. Карта: `years[].assessment`, критерии с устойчивыми ID, баллами и страницей. Паспорт 2027 использует статус `passport` и `exercise: null`; это позволяет добавлять проверенные нормы без ложной готовности упражнений. Дополнительную квалификацию добавляют отдельным файлом данных и в список сборки.

Новый компонент стека добавляется в `src/stack-tools.js`: объявление вариантов, генератор исходников и проверка общего контракта. Все текущие компоненты используют GET /api/items → массив объектов {id, name}. Выбор UI не должен менять данные; выбор сервера не должен менять результат. В ZIP есть команда запуска и объяснение взаимосвязей.

Сборка: `node scripts/build.mjs`. Проверка данных: `node scripts/validate.mjs`. Тесты: `node --test tests/core.test.mjs`. Проверка стеков: `node scripts/test-stacks.mjs`; переменная EXAM_PYTHON задаёт Python. Просмотр: `node scripts/serve.mjs`, порт задаётся PORT. Никакие npm-пакеты не нужны.

В текущей модели редакция содержит один предметный `exercise`. Для будущего полного многомодульного курса понадобится коллекция упражнений, сквозные зависимости, наполненные приложения и проверка всех вариантов; эту работу нельзя заменить снятием блокировки «Пробный экзамен».

## Граница готовности

Готов именно общий шаблон, шесть карт и учебные примеры. Редакция 2026 содержит 30 вариантов одного упражнения на программу. Редакция 2027 содержит паспорта и таймеры, без переименованных упражнений 2026. Полный пробный экзамен остаётся отключённым. Проверка `validate:exam` должна отклонять текущую демонстрационную поставку.

Публикация не выполнена: автор попросил сначала показать результат в чате. Исходные папки ИРПО, архив и творческий проект FIC не изменены.
