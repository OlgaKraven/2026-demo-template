# Разобранный учебный пример V00

Цена товара после скидки

Это разобранный фрагмент М2, а не полное приложение М2. Авторизация, интерфейсы ролей и остальные части исходного модуля здесь не реализованы. 40 минут — норматив всего М2; отдельного официального лимита этого фрагмента нет.

## Среда
JDK 17+; только стандартная библиотека.

1. Сохраните PriceDemo.java; имя класса и файла должны совпадать.
2. Выполните javac PriceDemo.java, затем java PriceDemo.
3. Создавайте BigDecimal из строк, а не из double; сравните четыре результата.

## Порядок решения
### Разобрать одну строку
Цена 1999,00; скидка 15%. Оставшаяся доля — 85 / 100.

### Выполнить расчёт
1999,00 × 0,85 = 1699,15. Исходную цену не заменяйте результатом, иначе её будет нечем показать рядом.

### Разделить признаки
Для строки проверяйте stock == 0 и discount > 15 независимо от расчёта суммы. Не используйте discount >= 15.

### Проверить границы
При скидке 0 итог равен исходной цене; при скидке 100 итог равен нулю. Отрицательная цена не является допустимым входом.

## Проверка
Для первой строки V00 итог 1699,15.

Скидка 15% не отмечена как превышающая 15%.

Строка без остатка распознана отдельно от скидки.

## Границы проверки
Пример собран и запущен в JDK 21.0.11; четыре результата сопоставлены с контрольным расчётом.

Это авторское учебное решение, не официальное решение ИРПО и не полный экзаменационный проект. Другие языки и программы допустимы на экзамене только при соответствии подтверждённой инфраструктуре площадки.
