# Проверка нового маршрута · 20 сентября 2026

Проверена чистая сборка нового курса в courses/is-2026. Node.js 24.11.1 на Windows; CI использует Node.js 22.

- npm ci, npm run build, npm test: 40 из 40 проверок проходят.
- Проверены исходные материалы, SQL, все 11 таблиц и связи интерактивной ER-схемы, компоновка таблиц и маршруты линий.
- В браузере Chromium проверены новый маршрут, открытие ER-справки, переход по её шагам, самостоятельная тренировка и подготовка пробного экзамена.
- Преподавательский пакет создан через форму, скачан и импортирован как задание студента.
- Проверены задание без таймера, задание с таймером, пауза и восстановление после перезагрузки.
- Вложение скачано из пакета; его текст совпал с исходным.
- Обновлённый пакет с тем же идентификатором, но другим содержанием получил отдельный прогресс. Возвращение к первоначальному пакету восстановило этап и отметки.
- Возврат из объяснения M2 в тренировку сохранил выбранный этап; перезагрузка также сохранила этап.
- На ширине 390 px нет горизонтального переполнения страницы тренировки. Проверены светлая и тёмная темы.
- Валидация отклоняет неизвестную версию, повторяющиеся этапы, недопустимые ссылки, повреждённый JSON и превышение размера вложений. Вывод заметок экранируется.

При проверке исправлены две ошибки: загрузка задания без ограничения времени и потеря номера активного этапа при сохранении заметок/отметок. Данные вложений хранятся в IndexedDB, чтобы не упираться в небольшой лимит localStorage.

Эта проверка относится к веб-интерфейсу. Повторный запуск WinForms и интеграционные проверки на серверах СУБД не выполнялись; исторические результаты примеров сохранены отдельно.
