# Статический шаблон подготовки к ДЭ · 09.02.07

Три независимые демонстрационные сборки и общий исходный код. Версия 0.1.0, 12 сентября 2026 года.

**Статус: рабочий технический шаблон с учебными примерами. Это не три полностью подготовленных экзаменационных курса.** Нормативы модулей 2026 сверены; каждый сайт содержит один отдельный учебный пример V00 и 30 вариантов именно этого упражнения. Для полного курса нужны остальные задания, приложения, решения и сквозная проверка. Версия 2027 явно ожидает подключения конкретных проверенных документов.

## Открыть готовый сайт

Распакуйте весь архив. В папке `dist` находятся три самостоятельных сайта:

| Папка | Программа | Что реально подготовлено |
|---|---|---|
| `dist/web/` | Веб и мультимедийные приложения | Фрагмент М2: четырёхкадровый слайдер; маршруты VS Code и WebStorm; 30 наборов изображений |
| `dist/is/` | Специалист по информационным системам | Учебный пример М3: запрос материальной стоимости заказа; маршруты PostgreSQL, MySQL, SQL Server; 30 наборов таблиц |
| `dist/programmer/` | Программист | Фрагмент М2: расчёт цены после скидки; Python, C#, Java; 30 предметных наборов |

Откройте `index.html` внутри выбранной папки обычным браузером. Ресурсы локальные, установка пакетов для просмотра не требуется. Для надёжного происхождения локального хранилища предпочтителен HTTP-просмотр или статический хостинг. Поведение сохранения при `file://` зависит от браузера.

В собранном сайте нет переключателя квалификаций. Каждый каталог готовится для отдельного адреса. Переключатель 2026/2027 относится только к редакциям одной программы.

## Проверить и пересобрать

Нужен Node.js 22.14+; фактически проверена версия 22.16.0. Внешних npm-зависимостей нет. Выполнять `npm install` или `npm ci` для этой поставки не требуется.

```sh
npm run validate
npm test
npm run build
npm run preview
```

Локальный адрес будет напечатан сервером, по умолчанию `http://127.0.0.1:4173`. Корневая страница этого сервера — навигатор разработчика по трём сборкам, а не общий публикуемый сайт для студентов.

```sh
npm run validate:exam
```

Последняя команда **намеренно завершается ошибкой для демонстрации**: не подключён полный курс. Не удаляйте этот запрет, чтобы получить зелёный отчёт. Снятие признака `demo` не создаёт недостающие задания и приложения.

## Работа студента

В режиме «Разбор» открыт отдельный V00: короткая теория, шаги, решение и выбор программы. В режиме «Моя тренировка» выбирается V01–V30, отображаются его условия и данные. Кнопка выдаёт ZIP только этого упражнения и варианта. Студент работает локально; файлы решения не отправляются на сайт.

Таймер имеет подтверждённый норматив родительского модуля. Для фрагментов он не объявляется официальным временем отдельного упражнения. Старт, пауза, продолжение, завершение и сброс выполняются явно. Истечение времени не удаляет файлы и не скрывает условие. Состояние сохраняется локально при доступном хранилище.

Кнопка «Пробный экзамен» отключена, поскольку в поставке нет полного сквозного комплекта. Для неполных модулей показан честный паспорт вместо вымышленного задания.

## Что менять при наполнении

Редактируйте соответствующий файл `content/<program>.json`, а не `dist/.../course.js`. После изменения запустите проверки и сборку. Идентификаторы вариантов и источников должны сохранять устойчивость.

В текущей модели у редакции один `exercise`. Полный многомодульный курс потребует расширения коллекции упражнений, разрешения зависимостей и сквозного режима. Три адаптера `content-tools.js` не являются универсальным генератором любого задания из КОД. Подробные требования расширения заданы в инструкции.

По умолчанию используется нейтральный знак «ДЭ», а не логотип организации. Фирменный логотип и тематический маскот из предыдущих проектов не получены и не встроены. Поля `brand` зарезервированы; подключение реальных изображений к отображению — отдельная правка общего компонента. Шрифтовых файлов в архиве нет; используется системный резервный шрифт.

Варианты не должны изменяться случайно при перезагрузке. Для новой версии измените `contentVersion`, согласованно обновите данные, документы и результаты проверки. Массивы редакций не должны наследовать время 2026 в неподтверждённый 2027.

## Размещение

Публикуйте содержимое только одной папки `dist/web`, `dist/is` либо `dist/programmer` на отдельном статическом сайте. Все пути относительные; собственный сервер и приём данных не нужны. Корень рабочего проекта, отчёты и будущие приватные материалы публиковать не следует.

Удалённые репозитории пользователя не изменялись. GitHub Pages, домены и реальные адреса публикации не настраивались.

## Что проверено

Автоматические тесты, воспроизводимость 90 наборов и формирование ZIP; SQL-логика на 31 наборе в SQLite; Python и Java; DOM-интерфейс и слайдер в Chromium, включая мобильную ширину. Подробный отчёт разграничивает запуск браузерного кода и полноценное HTTP-испытание.

Ограничение среды проверки: штатная навигация Chromium на HTTP и локальные файлы была заблокирована политикой окружения. Разметка и скрипты проверялись локальным внедрением в страницу. Поэтому нативная перезагрузка сайта, сохранение `localStorage`, действие CSP и реальные скачивания кнопкой не объявляются проверенными end-to-end. ZIP отдельно сформированы тем же клиентским кодом и открыты стандартным архиватором.

.NET, целевые серверы PostgreSQL/MySQL/SQL Server и сами графические редакторы не запускались. Полные задания и приложения 2027 не подключены. Это ограничения проверки, а не скрытые готовые возможности.
