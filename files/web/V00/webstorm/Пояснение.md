# Разобранный учебный пример V00

Слайдер из четырёх изображений

Это фрагмент М2. Он не заменяет дизайн всех страниц, формы, обработку ошибок и другие требования полного модуля. 90 минут — норматив всего М2, а не отдельного слайдера. Учебные SVG созданы для примера и не являются официальным приложением.

## Среда
WebStorm и браузер. Используется тот же проект без npm-зависимостей.

1. Откройте папку примера как проект; сохраните относительные пути assets/slide-1.svg и остальных изображений.
2. Откройте index.html в браузере из редактора либо напрямую из папки.
3. Проверьте те же переходы и размер 390 × 844. Разница редактора не изменяет условие и решение.

## Порядок решения
### Подготовить структуру
Разместите изображение, подпись и две настоящие кнопки. Путь к файлу задаётся относительно HTML.

### Сделать циклический переход
Новый индекс вычисляйте как (индекс + направление + 4) % 4. Добавление 4 предотвращает отрицательный результат при шаге назад.

### Подключить автоматический переход
Создайте один интервал 3000 мс. При ручном переключении начните этот интервал заново, чтобы следующее изображение не перескочило сразу после нажатия.

### Проверить отображение
Сохраните одинаковое соотношение сторон изображений; ширина ограничена шириной контейнера. Кнопки доступны с клавиатуры.

### Проверить без сети
Откройте index.html из папки решения, отключите сеть. Все изображения должны оставаться видимыми.

## Проверка
В папке четыре изображения; при перелистывании нет пустого пятого кадра.

После четвёртого кадра отображается первый.

При ширине 390 px страница не требует горизонтальной прокрутки.

## Границы проверки
HTML/JS совпадает с первым маршрутом; запуск IDE WebStorm здесь не выполнялся.

Это авторское учебное решение, не официальное решение ИРПО и не полный экзаменационный проект. Другие языки и программы допустимы на экзамене только при соответствии подтверждённой инфраструктуре площадки.
