# Фактическая проверка версии 0.1.0

Дата: 12 сентября 2026 года. Публикация не выполнялась. Проверялся локально подготовленный технический шаблон, а не три завершённые программы подготовки.

## Автоматические проверки

`npm run validate` — успешно для трёх программ. В каждой ровно 30 вариантов, отдельный V00, устойчивые данные и подтверждённая сумма времени 2026. Проверены форма таблиц, числа и отсутствие файлов решений в начальных пакетах.

`npm test` — 18 тестов, 18 успешно. Охват: паспорта, суммы времени, блокировка неподтверждённого 2027, запрет приёмки неполного курса, состояния таймера, сериализация, пауза и продолжение, перерасход, изоляция ключей, повреждённые записи, 90 повторяемых наборов, индивидуальные архивы, ручной результат SQL-образца, граница скидки, CSV, ZIP и экранирование текста.

`npm run build` — успешно созданы `dist/web`, `dist/is`, `dist/programmer`. Сборки используют собственный `course.js` и общую неизменённую клиентскую логику.

`npm run validate:exam` — ожидаемый отказ для всех трёх программ. Нет полного комплекта всех заданий и приложений. Этот отказ подтверждает действие ограничения, а не завершённость экзаменационного режима.

## Исполнение учебных решений

| Проверка | Результат | Ограничение |
|---|---|---|
| SQL: V00 и 30 вариантов | Все 31 набора выполнены в SQLite; итоги совпали | Это не запуск PostgreSQL, MySQL или SQL Server |
| Python Decimal | Пример выполнен в Python 3.13.5; проверены четыре результата, округление, нулевая итоговая цена и отклонение отрицательной исходной цены | Не проверены все версии Python |
| Java BigDecimal | Скомпилирован и выполнен в JDK 21.0.11; четыре результата совпали | Отдельно JDK 17 не запускался |

| Учебный слайдер | Проверены ручные переходы и автоматическая смена через 3 секунды в Chromium, ширина 390 px | Исходные локальные ресурсы внедрены в тестовую страницу из-за ограничений навигации |

## Браузер и визуальная проверка

Стандартная навигация Chromium к `http://127.0.0.1`, `http://localhost`, файловым URL и тестовому URL блокировалась политикой окружения (`ERR_BLOCKED_BY_ADMINISTRATOR`). Политика браузера не отключалась.

Для проверки интерфейса собственные подготовленные HTML, CSS и JS были внедрены в пустую тестовую страницу. Политика CSP исходной страницы не применялась в этом тестовом стенде; нативное хранилище исходного сайта не тестировалось. Ограничения сохранены в отчёте и не подменены заявлением о полном end-to-end тестировании.

В этом стенде для всех трёх программ проверены: отображение, переключение учебного и тренировочного режима, V30, старт и пауза таймера, смена программного маршрута, отключение времени при выборе 2027, отсутствие элемента загрузки файлов и отсутствие горизонтального переполнения всей страницы при 390×844. Визуальные снимки подготовлены при 1440×1000 и 390×844. После прокрутки страницы повторно проверено отображение мобильного текста.

Основной экран специалиста по ИС и мобильный экран программиста просмотрены. Остальные снимки сохранены для дополнительной проверки; автоматическое отсутствие переполнения не приравнивается к экспертной оценке дизайна каждого элемента.

Не подтверждены в обычной навигации браузера: реальное скачивание кнопкой, поведение CSP при размещении, восстановление нативного `localStorage`, файловый запуск всех трёх сайтов, несколько реальных вкладок одного origin, полноэкранный API и HTTP-переходы после публикации.

## Архивы и локальные файлы

Клиентская функция ZIP выполнена для 90 вариантов. Для V30 каждого сайта полученные бинарные архивы открыты стандартным ZIP-читателем, проверена целостность и соответствие манифеста. Предварительно сохранены пакеты V01/V30 и решения V00 для каждого программного маршрута. Они не содержат шрифтовых файлов.

Готовые исходники решений прочитаны и использованы в испытаниях. Кнопки выдачи присутствуют, но нативное браузерное скачивание не засчитано как пройденное испытание из-за вышеописанной блокировки навигации.

## Проверка экзаменационного основания

Проверены названия программ, коды 2026, состав базовых модулей и их длительность. Таблицы времени веб-программы и специалиста по ИС просмотрены как изображения. Для программиста использовано текстовое извлечение; получение изображения таблицы завершалось ошибкой.

Полные официальные приложения к заданиям не прочитаны и не включены в текущую поставку. Новые учебные данные не названы официальными приложениями. Конкретные комплекты КИМ 2027 для этих программ не подключены; факт сообщения ИРПО о публикации спецификаций указан отдельно.

Полный сквозной прогон экзамена, методическая экспертиза комиссией, проверка на студентах и испытание на конкретной экзаменационной площадке не проводились. Эквивалентность всех будущих полных вариантов должна проверяться после получения исходного комплекта.

## Необходимое продолжение перед полной программой

Получить точные задания и приложения выбранной квалификации и года; расширить модель нескольких заданий; заполнить весь V00 и все 30 сквозных вариантов; проверить решения в разрешённом ПО; реализовать полный пробный режим; выполнить обычные браузерные и площадочные испытания. Снятие ограничения готовности без этих действий недопустимо.
