# Разобранный учебный пример V00

Стоимость заказа по составу изделий

Учебный пример М3 на авторских данных. Он не воспроизводит не полученные приложения М1 и М2 и не заменяет весь экзамен. Таблицы здесь выданы как состояние после предыдущих модулей.

## Среда
Подготовленный сервер MySQL и MySQL Workbench; кодировка utf8mb4.

1. Создайте отдельную учебную схему и назначьте её активной.
2. В SQL Editor выполните setup.sql. Затем выполните solution.sql; все таблицы должны находиться в выбранной схеме.
3. Сравните число строк и суммы. Сохраните SQL, а не снимок результата вместо запроса.

## Порядок решения
### Прочитать ключи
order_items.product_id связан с recipes.product_id, а recipes.material_id — с materials.id. Количество относится к позиции заказа, а норма — к одному изделию.

### Проверить соединение
Для каждой позиции заказа после соединения должно появиться столько строк, сколько материалов в рецептуре этого изделия. Произвольное соединение без условия умножит строки.

### Вычислить вклад
Умножьте три величины для каждой строки соединения. Не складывайте цену материала с количеством изделия.

### Собрать итог заказа
Сгруппируйте строки по идентификатору заказа и сложите вклады. Округлите итог до двух знаков.

### Проверить на примере
В V00 первый заказ содержит три полки и две панели. Стоимость полки: 0,6 × 1200 + 2 × 180 = 1080. Панели: 1,2 × 1200 + 0,15 × 1600 = 1680. Заказ: 3 × 1080 + 2 × 1680 = 6600 рублей.

## Проверка
В результате два заказа, а не четыре строки состава.

Сумма V00 для заказа 1001 — 6600,00, для 1002 — 1080,00.

Цена материала используется один раз на каждую строку его расхода.

## Границы проверки
Синтаксис базового SELECT сопоставлен с документацией; сервер MySQL здесь не запускался.

Это авторское учебное решение, не официальное решение ИРПО и не полный экзаменационный проект. Другие языки и программы допустимы на экзамене только при соответствии подтверждённой инфраструктуре площадки.
