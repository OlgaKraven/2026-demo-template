# Учебный маршрут и тренировка

Кнопка «Тур по сайту» в шапке объясняет основные разделы. В обучении, тренировке, пробном экзамене, примерах, справочнике и конструкторе задания есть отдельные гиды. В окнах ER-схемы, просмотра файлов и презентации доступны свои подсказки. Тур не запускает таймер и не изменяет ваши отметки.

## Обучение

Выберите свою СУБД в верхнем меню. Пройдите маршрут слева: документы → ER-схема → база → расчёт → приложение → проверка и сдача. На первом экране нажимайте реквизиты JSON: справа показано соответствующее поле модели и его происхождение. На этапе ER откройте пошаговую схему; полная схема и PDF остаются доступны. Отметки в конце этапа — самопроверка, а не оценка.

## Тренировка по варианту

Откройте «Тренировка» → «Мой вариант» и выберите номер, назначенный преподавателем. У каждого номера свои условия и материалы, пять этапов, заметки и самопроверка. Скачайте материалы, выполняйте работу в своих программах. Таймер на 150 минут — ориентир; его можно поставить на паузу. При переходе к другому варианту запущенный отсчёт продолжает идти. Для каждого варианта прогресс изолирован.

«Нужна подсказка» открывает объяснение на учебном примере. Кнопка «Вернуться к заданию» возвращает к вашему варианту и этапу. Полесье — пример, его данные не заменяют ваши.

На последнем этапе нажмите «Подготовить сдачу»: появятся список результатов и скачивание протокола самопроверки. Протокол содержит заметки и отметки, но не SQL, PDF и C#-проект.

## Задание преподавателя

Преподаватель открывает «Преподавателю» → «Создать тренировку», задаёт общее условие, выбирает от одного до пяти этапов и заполняет их задания, результаты и критерии. Можно разрешить учебные подсказки и задать время; 0 означает работу без таймера.

В пакет можно включить до 12 вложений, каждое до 5 МБ, общий размер до 12 МБ. Для больших файлов добавляйте HTTPS-ссылки; доступ к ним настраивается в вашем хранилище. Нажмите «Проверить и подготовить задание», затем «Скачать файл задания». Передайте полученный JSON студентам. Текстовый черновик сохраняется в браузере; вложения при возвращении к редактору выбирайте повторно.

Студент открывает «Тренировка» → «Задание преподавателя» и выбирает этот JSON. Условия и вложения сохраняются в IndexedDB браузера; отметки и таймер — отдельно для содержания каждого пакета. Повторное открытие того же пакета восстанавливает прогресс. Изменённый пакет начинает отдельную тренировку. Одновременно на экране доступен один преподавательский пакет: для возвращения к предыдущему откройте его файл.

Данные не отправляются на сервер. При недоступном хранилище показывается сообщение; сохраняйте исходный пакет задания. Очистка данных браузера удаляет локальный прогресс. Сайт не принимает решения и не выставляет оценки: передавайте результаты способом, указанным преподавателем.

## Пробный экзамен и справочные материалы

«Пробный экзамен» сохраняет 30 вариантов, подготовку к старту, общий таймер 150 минут без паузы и итоговый протокол. Состояния экзамена и тренировки разделены. «Справочник» содержит инструкции для программ, «Примеры» — готовые проекты, «Критерии» — официальные критерии. В разделе преподавателя сохранены презентации и настройка профиля.

## Разработка

Node.js 22+: npm ci, npm run build, npm test, npm run preview. Источники находятся в src, content, lessons, examples и materials; site создаётся сборкой. Интерактивная ER-схема строится из SQL и пояснений; PDF/SVG создаются отдельным scripts/diagram.py. Не редактируйте только site.
