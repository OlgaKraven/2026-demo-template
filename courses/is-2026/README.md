# Мой учебный проект · ДЭ 2026

Учебный маршрут для специалиста по информационным системам на базе проекта demo-dkip-2026. Сохранено оформление исходного проекта: красный акцент, шапка специальности, чёрный баннер с носорогом и светлая/тёмная тема. Учебный маршрут расположен слева. Общий тур и гиды разделов объясняют действия на текущем экране.

- Обучение: документы → ER-схема → база → расчёт → приложение → сдача.
- Тренировка: 30 вариантов или пакет задания преподавателя с вложениями.
- Пробный экзамен: самостоятельное выполнение пяти модулей за 150 минут.
- Справочник, готовые примеры C# WinForms для MySQL/PostgreSQL и презентации.

Начало работы: npm ci → npm run build → npm test → npm run preview. Требуется Node.js 22+. Готовый сайт собирается в site. Для сохранения заданий и прогресса открывайте через HTTP/HTTPS.

[Инструкция преподавателю и студенту](docs/USER_GUIDE.md). Исходный проект: https://github.com/OlgaKraven/demo-dkip-2026 (02f1daf). Источники и атрибуция сохранены в docs/sources.json и docs/LECTURE_TEMPLATE_LICENSE.txt.

Сайт не проверяет и не принимает решения: SQL, PDF и C# сохраняются и передаются отдельно. Для запуска скачиваемых приложений нужны Windows, .NET Framework 4.8 и выбранная СУБД.
